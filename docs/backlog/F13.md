# F13 — Protocol Lab

So sánh Polling, Long Polling, SSE và WebSocket thuần bằng cùng workload.

**Chức năng:** F13 · **Key points:** KP1 · **Ưu tiên:** MUST
**Phụ trách chính:** Nguyễn Thái An - 52400064 (Lab & Admin)
**Phối hợp:** TV1 phần FE; TV2 phần BE/infra; TV3 Lab/Admin và điều phối test.

## Checklist công việc con

- [x] **FE:** Trang `/lab` chọn giao thức, cùng workload, biểu đồ p50/p95/từng tin và request/header ước lượng, bảng chi tiết, hủy bài đo, JSON export; cấu hình kết quả được giữ riêng với form.
- [x] **BE:** REST ping/poll/long-poll/SSE và raw /lab/ws, authentication/session isolation, bounded history/timeout; script cùng workload đo bốn giao thức.
- [x] **Test:** Cùng preset cho đủ bốn giao thức; lịch gửi tuyệt đối, cùng đồng hồ monotonic, nearest-rank, accounting header/frame riêng; test parser SSE, hủy, session isolation, raw WS và browser/mobile đã pass. Giới hạn jitter/thời lượng quan sát được ghi rõ trong phương pháp đo.
- [x] **Docs:** Thiết kế F13/KP1 bằng tiếng Anh, README/API/cách test đã cập nhật; lưu JSON và ảnh desktop/mobile thực tế tại `docs/evidence/f13` để dùng cho báo cáo/demo.

## Tiêu chí nghiệm thu

- [x] Có kết quả của đủ 4 giao thức, p50/p95 latency, request count và header bytes ước lượng; tách HTTP handshake, WS frame overhead, payload/TLS; không dùng STOMP làm WebSocket thuần.
